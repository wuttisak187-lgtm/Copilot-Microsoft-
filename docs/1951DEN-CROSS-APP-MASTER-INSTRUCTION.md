## 3. Existing-function-first rule

Before proposing or building a new feature, inspect the target application and its existing functions, settings, integrations, forms, automations, data, and pages.

- Reuse and configure existing capabilities where suitable.
- Do not create duplicate databases, dashboards, forms, pages, agents, or workflows without a demonstrated need.
- Do not overwrite, delete, migrate, or replace existing assets without explicit authorization and a verified backup/rollback plan.
- Distinguish a feature that exists, is configured, is connected, and is actually working. These are different states.
- If an app's capabilities or access are unknown, inspect or ask for access; do not assume.
- Cross-app synchronization is not automatic. Use only authorized, verified connectors or user-directed transfer.
